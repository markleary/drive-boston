# Drive Boston - Greater Boston

A single-player, free-roaming browser driving prototype built with Three.js, TypeScript, Vite, and Rapier. Explore Boston from Charlestown and East Boston to Mattapan and Jamaica Plain, plus Cambridge, Somerville, Brookline, Chelsea, Everett, Medford, Malden, and Melrose, in an ivory coupe or an inspection helicopter. Only Roslindale, West Roxbury, Hyde Park, and the Harbor Islands are left out. Streets and building models come from Boston's and Cambridge's public data, OpenStreetMap footprints (shaped by the MassGIS assessor records in the four northern cities) fill the towns without open 3D models, and an offline USGS elevation grid supplies the real terrain. The world streams in 1 km tiles around the player, so the whole 207 km² region is one continuous drive. Desktop is the primary target. Touch devices start in Balanced mode with direct canvas rendering, 1024-pixel shadows, nearby skyline chunks, and a smaller detailed neighborhood radius. Mobile omits ambient occlusion, bloom, multisampled HDR buffers, dynamic reflections, raised curb decoration, extra facade/rooftop meshes, and startup night-shader warmup; selecting Detailed on a touch device retains these memory limits. Mobile road buffers share identical vertices without changing their triangles, and mobile tile assembly avoids an additional full-tile buffer repack. Night shaders compile when Night is first selected, which may briefly pause rendering.

## Run

Node.js 24 LTS is recommended.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite, then select **Start driving**. No API keys, accounts, or runtime map services are needed. All geographic assets ship with the application. The data package totals approximately 144 MB before transfer compression, but a session only downloads the 9.5 MB city index, the 16 MB terrain grid, the 5 MB far-building hulls, the 0.3 MB railway track, and the 1 km building tiles near the player (about 365 KB each, 265 in all). Subsequent visits can reuse the browser cache.

```sh
npm run build
npm run preview
```

The `dist/` directory is a static site. Vite uses a relative base so it can be hosted at a GitHub Pages repository path.

The web manifest, Android icons, and Apple home-screen tags allow installation from the browser’s **Add to Home Screen** action. Android requests fullscreen; iOS opens without Safari’s toolbar when **Open as Web App** is enabled. Both orientations are supported. This is an online game; home-screen installation does not cache the city for offline use. Static Open Graph and Twitter metadata use `public/social-preview.jpg`, a 1200 × 630 capture of actual desktop gameplay, for shared links.

The public prototype is hosted at **https://markleary.github.io/drive-boston/**. The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the site and publishes `dist/` to GitHub Pages on every push to `main`, so merging a pull request deploys it; the workflow can also be started by hand from the repository's Actions tab. The repository's Pages source must be set to GitHub Actions (Settings, Pages) for those deployments to be accepted; the former `gh-pages` branch is no longer used. The workflow only builds and deploys; it does not run the test suites.

To check a build locally, run `npm ci`, `npm run build`, and `npm run preview`.

Map generation compiles shared street junctions and tile-edge polygons, reconnects source-confirmed GIS/OSM gaps, grades connected ramp pieces, and paves terrain where it meets a bridge approach. Before shipping a map extension, run `npm run validate:data` and `npm run audit:roads -- --output /tmp/road-generation-audit.json --strict` after the generation chain in `CLAUDE.md`. The strict audit currently flags unresolved steep approaches listed in [the generation report](reports/road-generation.json); it must not be treated as a passing certification of the entire map. See [DATA_SOURCES.md](DATA_SOURCES.md#road-generation-continuity-audit) for the generation rules and limits.

Sullivan Square's Mystic/Main Street rail crossing, Maffa Way corridor and two station parking/access gaps have dated generation-input corrections checked against 2025 aerial imagery and the supplied satellite references. The bridge follows a straight axis between its preserved street landings, with a constant estimated 12 m deck width and about 1.2% grade. Maffa Way keeps an estimated 14 m carriageway under I-93 and past the station parking lots; obsolete curb outlines cannot pinch it. Both parking sections between Maffa and Main have even sidewalk and curb borders with their access aisles kept open. Physics, generator and data checks run on pull requests and before deployment; the road-audit baseline gate rejects new or worsened defects. The separate strict audit still reports 20 steep segments elsewhere.

## Play

Open **M** to browse the atlas and choose one of 74 starting points: the original Back Bay and Mission Hill places, Fenway Park, Kenmore Square, Symphony Hall, the State House, Downtown Crossing, Chinatown Gate, South Station, Boston Common, and the Public Garden, and now Faneuil Hall, the Old North Church, the Custom House, City Hall Plaza, TD Garden, the Museum of Science, the Longfellow Bridge, the Seaport ICA, Castle Island, Dorchester Heights, the JFK Library, Nubian Square, Franklin Park Zoo, Jamaica Pond, the Arnold Arboretum, Mattapan Square, the Bunker Hill Monument, the Charlestown Navy Yard, Maverick Square, Logan Airport, Harvard Stadium, the Chestnut Hill Reservoir, Harvard Square, Harvard Yard, the MIT Great Dome, Kendall Square, Porter Square, Fresh Pond, Davis Square, Union Square, Prospect Hill, Assembly Row, Coolidge Corner, Brookline Village, Larz Anderson Park, Chelsea Square, Bellingham Square, Mary O’Malley Waterfront Park, Everett Square, Encore Boston Harbor, Wellington and Station Landing, Medford Square, Tufts University's Goddard Chapel, Malden Center, Fellsmere Park, Oak Grove, Pine Banks Park, the Melrose YMCA, Melrose City Hall and Memorial Hall, Ell Pond, Bellevue Avenue, Melrose Highlands, Mount Hood Park, both directions of the Tobin Bridge, and three Big Dig entrances. **Mission Hill · Parker Hill** starts on an uphill stretch of Parker Hill Avenue, and **Brigham Circle** explores the Huntington Avenue approach. Every destination has a connected surface-road route from the Boylston Street spawn, including East Boston via Chelsea and the Chelsea Creek crossings, and Melrose via the Mystic River bridges. The harbor tunnels remain unmodeled. The Mission Hill summit is about 59 m (193 ft) above the original Boylston starting point.

**GPS directions.** In the atlas, click or tap any street to set a destination. The fastest legal route from where you are is highlighted in blue on the atlas and the minimap, and the location pill at the top of the HUD becomes a turn-by-turn display: an arrow, the distance to the next maneuver and its instruction (for example "300 ft · Turn left on Dartmouth St"), plus the destination street with the distance and driving time left (for example "To Lansdowne St · 1.4 mi · 4 min"). Routing covers every mapped street, keeps to one-way streets, prices left turns above right turns, and recalculates when you leave the route or drive the wrong way along it. In the helicopter the guide points straight at the destination instead, with a dashed line on the maps. Arriving ends the route, and **Clear destination** in the atlas resets it at any time. With a controller, RB sets a destination under the atlas crosshair and LB clears it.

Neighborhood names and boundaries follow the [City of Boston neighborhood GIS layer](https://gisportal.boston.gov/arcgis/rest/services/Basemaps/Boston_Basemap_Cached_WM/MapServer/16) and, for Cambridge, Somerville, Brookline, Chelsea, Everett, Medford, Malden, and Melrose, the City's surrounding-town layer. That layer calls the Fenway/Kenmore area **Fenway** and identifies **Longwood**, **Bay Village**, and **Leather District** separately. Boston Common and the Public Garden are included explicitly as parks. The GIS layer places both within Beacon Hill, while the city's park directory describes them as Downtown; the game consistently uses the GIS polygons for atlas and HUD labels.

Hard braking and sideways slides leave temporary tire marks for both cars and the Ultra Bee: rubber streaks on pavement (on the surveyed Zakim Bridge and Charlestown viaduct too, along the Interstate 93 and Leverett Connector lanes) and ragged, churned-soil tracks on lawns. Marks fade away after about 24 seconds on pavement or 35 seconds on grass; airborne wheels leave no tracks.

Random roadworks close one curbside lane with tapered lines of reflective orange cones, warning signs, and parked dump trucks or excavators. Sites require measured pavement wide enough for two lanes in the same direction, keep junctions and transit routes clear, and leave an open lane that NPC traffic merges into. Cones can be knocked over; heavy equipment has solid collision shapes. The layout changes on reload and stays fixed during a session, with only nearby sites loaded. Lane eligibility is inferred from pavement width; roads without measurements stay clear. On Interstate 93 a work zone closes a carriageway's outside lane into the next one (60 m of work between 45 m tapers) every 1.5 to 2.5 km along each direction, clear of the ramps and the closed ends.

A standard (Xbox-layout) controller works everywhere, including the title screen: press **A** to start. Browsers only reveal a controller after one of its buttons is pressed with the page focused, so a freshly plugged-in pad shows up on its first press. While a controller is the last device used, the HUD hints, settings reference, map caption and title screen show Xbox button badges instead of keys; pressing a keyboard key switches them back. Unplugging the controller mid-drive pauses the game.

In **helicopter mode**, W/S fly forward/backward, A/D move sideways, Q/E turn, **Space rises**, and **Shift descends**. Forward flight reaches about **120 MPH**; releasing the controls brings the aircraft into a hover. The HUD control hints stay visible throughout driving and flight while the HUD is enabled. C switches between chase, cockpit, and overhead views; drag vertically to tilt the aerial inspection view and use the wheel for distance. The instruments display speed in MPH and altitude in feet above the terrain directly below the helicopter. Flight stays inside the prototype boundary, at least 4 meters above terrain and below a ceiling 350 meters above the highest terrain point, with conservative rotor clearance around buildings and continuous collision checks against bridge decks and detailed building openings. This is assisted exploration flight; landing and aerodynamic damage are not simulated.

In **walk mode** (4), you step out beside your vehicle, which stays where you left it with its brakes held. W/S/A/D move relative to the view (A/D also swing the over-the-shoulder camera after you, so the keyboard alone walks an arc), Q/E or a mouse drag turn the view, **Shift runs** (about 12 MPH against a 4 MPH walk) and **Space jumps**; curbs and steps up to about 40 cm are simply walked over. C switches between the over-the-shoulder, first-person and overhead views. The player is drawn with the sidewalk walkers' tailored figure in a close-up build: anatomical shoulder height and neck, a torso that narrows to the waist, arms that hang beside the ribs, a breathing idle stance, a head that turns toward where you look, and separate walking, running (lean from the ankles, a flight phase between strides, heel kick, pumping bent arms) and airborne poses. Traffic and buses treat a player on foot as something in their lane and slow or stop for them; a vehicle that still reaches you above about 3 MPH knocks you down exactly as it does a sidewalk walker (thrown, tumbling, lying still, then getting up), after which you walk on. **R** puts you back on the closest sidewalk if you get stuck. Returning to the car or bike gets in where it stands if it is within 12 m, and otherwise brings it to the nearest street beside you; switching to the helicopter lifts off from where you stand, and switching from it sets you down on the sidewalk below. On touch screens the helicopter pad moves the walker, with its altitude pair relabelled **Run** (hold) and **Jump**.

In **Ultra Bee mode** (2), ride a white/yellow electric dirt bike with a dark-cyan forged-frame likeness, knobby spoked wheels, and a rider wearing an original red Fox V1 Toxsyk-inspired motocross helmet with a vented chin guard, full black face mask, and black/white graphics. W/S control throttle and brake/reverse assist; A/D turn the front wheel, forks and handlebars as the bike banks; the rider’s hands follow the grips. Space applies both brakes. **Accelerate above walking pace, then press X** for a wheelie lasting up to three seconds; braking or releasing the throttle brings the front wheel down. Release and press X again after recovery to repeat. Touch devices gain a Wheelie button; controller X performs the same stunt. C includes a rider-eye camera. If a crash leaves the bike on its side, automatic recovery places it upright on the nearest clear road near the crash, preserving the road level at bridges and underpasses. R still returns to the Boylston starting point.

The model uses the **original Ultra Bee X** specifications, rather than the newer HP: [manufacturer reference](https://us.surron.com/ultrabee/) and [specification sheet](https://sur-ronglobal.com/surron-ultra-bee/). Bike mass is 85 kg plus a 70 kg rider, peak output 12.5 kW, rear-wheel torque 440 Nm, wheelbase 1,380 mm, and suspension travel 240 mm. Flat-road simulation reaches 0–50 km/h in about 2.3 seconds and approximately 56 mph. Two Rapier wheel rays, rear-wheel drive, speed-sensitive steering with matching tire and lean targets, bank/balance torques, rolling resistance, aerodynamic drag and mild regenerative braking give it motorcycle handling. The wheelie lifts the physical front contact. Automatic rider balance makes keyboard/touch riding accessible; it is a game approximation, not a full motorcycle dynamics model. Electric motor whine replaces the car engine; battery depletion and range are not simulated.

Switching to helicopter launches above your ground vehicle, which stays in the shared traffic/physics world with its brakes held while you fly. Switching back to the same ground vehicle returns to it; choosing the other ground vehicle changes it in place and clears momentum. Map destinations reposition the active vehicle and wait for the tiles around it to stream in. The saved browser position is always the ground vehicle's location; reload starts with the car.

Touch devices default to a proportional steering pad on the left and separate Gas/Brake pedals on the right. Brake stops the vehicle without selecting reverse; the D/R selector unlocks only near a standstill. **Settings → Touch controls** offers a saved **Combined joystick** alternative: up accelerates, left/right steer, and down brakes then reverses. Handbrake remains a separate action, and the bike adds Wheelie. Mobile vehicle switching is in settings; helicopter mode keeps dedicated movement, turn, and altitude buttons. Portrait hides the minimap, keeps the full atlas available through the map button, and reframes the chase camera above the thumb controls. Landscape places the minimap at the upper left. The atlas supports touch pan and pinch zoom. Rotating, leaving the app, opening a menu, or changing controls releases held input. While driving or riding, the label at the top of the HUD names your street and, below it, the next cross street ahead in your direction of travel. The map includes real building footprints, street labels, City of Boston neighborhood and town boundaries, parks and water, landmarks, pan/zoom, and safe starting points near each landmark. Desktop places appear in a scrolling side panel; phones use a compact scrolling grid below the map. The overview fits the whole metro area, and the target button zooms to your current location. Map/settings screens pause the simulation. Position is saved locally in the browser.

Open **Escape → Graphics** to switch between **Detailed** (contact shading, subtle bloom, frequent local reflection updates) and **Balanced** (lighter shadows and rendering). Both retain the same buildings, streets, traffic, and controls.

Press **P** for performance stats or **backtick (`)** for the debug/location panel; WASD steering remains unchanged. **Copy debug report** captures the active car or helicopter's world coordinates, nearest road name and ID, neighborhood, heading, terrain clearance, view settings, and rendering stats for reporting a problem. Coordinates are meters in the game's local world: X increases east, Z increases south, and Y is height above the local datum, not latitude/longitude or elevation above sea level. Render totals include shadows, reflections, and postprocessing; frame time is a measured frame interval rather than GPU execution time.

## Scope and fidelity

This is a free-roaming exploration prototype of one metropolitan region. The driving surface uses sampled bare-earth terrain with procedural street grading. Source-mapped Bowker/Charlesgate decks and ramps, plus the lower Commonwealth Avenue bridges over the Muddy River, have independent collision surfaces and estimated elevations. Elsewhere, streets that the sources mark as crossing water or another road level receive estimated deck profiles, using 6.4 m lifts for raised endpoints and smooth approaches, including the Charles River bridges to Cambridge, and each estimated bridge over water is then levelled into one deck that slopes gently between its own at-grade junctions and stays above the terrain under its ramps, while on land a lifted stub that a ground street continues is brought back to the ground (Huntington Avenue at the Brookline line), an approach that ran under its own embankment is held over it, and the clipped Pond Avenue ramp reaches the Jamaicaway loop; deck parapets stand only where a deck edge is clear of the ground beside it or, beyond the first 12 m from a junction, where that ground falls away within a few metres, so ramp mouths and at-grade approaches stay open through their street junctions while embankment approaches stay railed; other interstates, the Turnpike, Storrow Drive, and harbor tunnels remain excluded apart from the two Leverett Connector continuations and the Tobin Bridge with its local access ramps. East Boston connects by road through Chelsea. The Tobin’s Boston access follows mapped ramp and tunnel alignments as open, terrain-adjusted decks with clearance over retained survey structures; its heights and approach grades are game estimates, and its deep tunnel system remains unmodeled. Longfellow has an original procedural interpretation of its four granite salt-and-pepper towers, eleven steel arch spans, piers, sidewalks, and central rail reservation. Bridge details follow both carriageway ramp profiles, and the rail reservation stays clear of trees. Harvard Bridge has continuous deck joins, one straight Boston approach ramp, a connected Cambridge approach above Memorial Drive with correctly sized slip roads, and painted Smoot ticks and labels on its eastern sidewalk. Water stays horizontal at a consistent estimated level for each basin or river reach, meets rounded, gently blended shoreline banks, and preserves paved bank roads and underpasses as tiles load. Small park footbridges have arched physical decks that the Ultra Bee can cross; switching vehicles and reloading on a deck preserve its height. Land-side surveyed viaducts have ground-reaching supports whose caps stay beneath the deck they carry; the Zakim cable span retains its surveyed geometry, with the Central Artery bores now connected to its southern approaches. The Zakim and its Charlestown I-93 viaduct are paved as interstate carriageways: each roadway is measured between its surveyed barriers every 2 m and receives asphalt, solid edge lines and dashed 3 m on 9 m lane lines, with the lane count estimated from the measured width. Bridge guardrails and edge markings follow exposed deck edges, with openings at overlapping ramps and merges; visible barriers and collisions use the same clipped geometry. Mixed Boston/OSM bridge continuations share deck heights and end sections; the Memorial Drive U-turn joins both carriageways, including its interior-road junction. The short New Rutherford underpass has connected lower ramps, a local terrain cut, and retained upper Austin Street decks. The active Leverett Connector ramps continue from the survey cutoffs to Leverett Circle on mapped alignments; the actual unfinished Inner Belt ramp northwest of them remains unchanged. These road cuts and fine curb ramps are estimated rather than individually engineered. Raised curb faces and most landscaping remain visual detail; the added shoreline slopes share their visible geometry with collision. Buildings are seated level on their sampled footprint high point, with retaining foundations where needed; this is an approximation on steep sites. Road widths in the data are approximate class guesses; the drawn roadway follows the surveyed curbs in Boston and synthetic curbs in the towns, and where no curb was measured (deck roads, gaps in the survey) the guessed width is used. Lane markings, façades and street furniture are artistic interpretations. Storefront labels are fictional; signals use a simplified shared cycle. Pedestrians remain on sidewalk routes and are ambient characters. Most source building surveys date to 2011; the June 2026 model package is not a fresh survey. Buildings whose convex footprints cross ground-level road centerlines automatically use detailed triangle collision, preserving openings that exist in the source mesh. The Prudential complex, 145 Dartmouth, NEXUS, Fenway Park, the Logan terminals, and the Zakim Bridge also retain explicit exact-mesh handling. BUMC on Massachusetts Avenue required a separate geometry correction: the original survey contained walls across the street, so selecting its source triangles alone did not open the crossing. Its corrected passage has an estimated six metres of clearance and is tested by driving through both facades in both directions, with additional bus-height checks across the lanes. Other buildings retain convex collision proxies that can close courtyards; a city-wide clearance audit flags source-model roadway intrusions for review. The Prudential crown adds a solid box around its slab overhangs. OpenStreetMap buildings in the towns are flat-roofed or gabled extrusions of mapped footprints, not surveyed massing; in Everett, Medford, Malden, and Melrose most are houses generated from the style, storeys and year their parcel's assessor record gives, an interpretive typology rather than a survey of any one house, and their driveways are laid out from the parcels. The Orange Line and Haverhill Line track is static, with estimated heights, and no trains run on it yet. Interstate 93 north of the tunnel follows OpenStreetMap's alignment and lane tags on estimated deck heights, with trench cuts under its three overpasses and a southbound lower deck held beneath the surveyed Charlestown viaduct that replaces the survey's City Square ramp (cut out of the survey mesh); there is no southbound exit to Storrow Drive or the Leverett Connector, the reversible HOV lanes in Somerville are not modeled, and both carriageways end at concrete barriers at the Medford/Stoneham line. Florence Street in Malden crosses Dartmouth Street on an estimated deck with less clearance (about 3 m) than a real bridge would give. Tiles beyond about 1.1 km from the player are drawn as hulls only; a fast helicopter can briefly outrun the detailed tiles. The map offers landmark repositioning, not turn-by-turn navigation. There are no missions, multiplayer, or enterable interiors.

The real model geometry is retained, quantized to 1 cm (2 to 5 cm for the three largest meshes) inside the tiles, with its vertical placement reconciled to the terrain; the game does not bundle photographic façades. Fenway is a detailed exterior/aerial landmark. Its source stadium collision preserves the open field, but the generated field, seats, and stands are decorative and do not establish a playable stadium interior. House façades, house colours, porches, planting, and pedestrians are procedural interpretations rather than a record of each real address or tree. See [DATA_SOURCES.md](DATA_SOURCES.md) for exact sources, licenses, filtering, source dates, coordinate conversion, and asset regeneration.

Reviewing unable12’s Slop San Francisco informed the shared-terrain and draped-road architecture used for the Mission Hill expansion. The implementation and procedural art here are original; its source code was not copied.

## Structure

- `scripts/`: reproducible GIS and OBJ preprocessing, offline grading, and the tile packer.
- `public/data/`: the city index, terrain and far-building sidecars, 1 km tiles, and source provenance.
- `src/physics/`: Rapier simulation.
- `src/render/`: scene, materials, landmark details, and player vehicle.
- `src/simulation/`: traffic, road helpers, and sound.
- `src/ui/`: DOM interface and Canvas maps.

The simulation uses a fixed 60 Hz step and remains separate from the Three.js view. Current work focuses on visual polish and free-roaming driving across the region. Future improvements can refine street grades, junctions, bridge profiles, and district landmarks without replacing the shared terrain foundation or the tile format.

Static streamed details use material-compatible Three.js `BatchedMesh` submissions with 128 m triangle chunks, each culled against the view, the shadow map and the reflection captures from bounds taken when its tile is built: nothing in them moves, so there is no per-frame sorting, matrix lookup or texture upload. This keeps the source geometry, UVs, materials and shadow detail while reducing work outside the view. Street pavement, sidewalks, driveways and park ground are draped on the terrain as shared-vertex meshes whose clipped fragments are merged again inside each terrain triangle (the same coverage in about a fifth of the triangles and a tenth of the memory), shaded with the terrain's own normals; the distant city draws each hull as an instance of one box; Green Line track is laid as the player comes within sight of it. Traffic body and wheel batches also cull each vehicle separately for the view, shadows and reflections, and sidewalk walkers outside the view (and out of reach of it with their shadows) are left out of its draws. Detailed desktop helicopter views cover the nearby district with shadows (1.1 km shadow half-extent, with tree silhouettes casting out to their 900 m visibility limit), using the existing 4096² map; driving, Ultra Bee, Balanced and mobile retain their smaller shadow budgets. The postprocessing chain keeps 4× MSAA on the HDR scene pass; fullscreen AO/bloom composition uses a single-sample target. Tile building budgets spare work toward a 60 Hz frame interval, with a small minimum slice that grows with travel speed when a tile ahead is due; no tile is finished in a single frame while flying, and shore-bank and rock colliders are added a few thousand triangles a frame. On desktop new geometry is sent to the GPU half a megabyte a frame before it is shown, and the models, textures and shader variants of the whole scene are sent while the game loads, so nothing uploads or links in the frame that first sees it. The helicopter view's shadow map has half-meter texels, which cannot resolve window reveals, shopfront fittings, signal heads or lamp poles: those cast only into the close shadow maps of the ground views. The minimap's street map is redrawn eleven times a second and slides under the player's arrow every frame in between. Trees have three levels of detail by distance, each with its own arrangement of leaf cards; a level's cards shrink as the next level's grow, so a tree never changes shape at once as the camera passes (from the helicopter that boundary used to sweep across the middle of the view). On phones each finished tile drops its JavaScript copies of vertex and index arrays once WebGL holds them (about 100 MB around Copley Square), so a WebGL context restore rebuilds the resident tiles before play resumes. Performance remains dependent on the viewpoint, display size, GPU and loading state.

Open Settings → **Your car** to select the **Harbor S4**, the original coupe with refined paint/window details and an actual 60 mph top speed, or the **McLaren GT**, an original photo-referenced model with rear-wheel drive, seven automatic gears, a 203 mph top speed and acceleration/braking calibrated against McLaren's specifications.
